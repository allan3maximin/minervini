Minervini投資法(SEPA)の要点

SEPAの基本サイクル

Mark MinervinìのSEPA(Specific Entry Point Analysis)は、機関投資家の資金が入り始めた「成長株」を、ベースを抜けた瞬間に低リスクで拾いに行く手法。銘柄は無限にあるステージ(停滞→上昇→天井圏→下降)を巡っており、狙うのはステージ2(上昇局面)の初期だけ。ステージ1(底固め)からステージ2への転換をトレンドテンプレートで判定し、ステージ2の中でのVCP(出来高・値幅の収縮)完成をエントリーの引き金にする。

トレンドテンプレート(8条件)

ステージ2にあることを機械的に確認するための8つのMUST条件。1つでも欠ければステージ2とは認めない。

  1. 終値が150日線・200日線より上
  2. 150日線が200日線より上
  3. 200日線が1ヶ月以上上向き
  4. 50日線 > 150日線 > 200日線 の並び
  5. 終値が50日線より上
  6. 52週安値から+25%以上離れている
  7. 52週高値から-25%以内(高値圏に近い)
  8. RSレーティング(相対的強さ)が70以上、理想は80〜90以上

VCP(ボラティリティ収縮パターン, V1〜V7)

強い銘柄でも上昇前には必ず「収縮」する。売り圧力が減衰し、供給が枯れたことを値幅・出来高の両面から確認するのがVCP。

  1. V1 収縮(押し)の回数が2〜6回
  2. V2 収縮の深さが段階的に浅くなっていく(例: 25%→15%→8%)
  3. V3 最初の収縮が35%以内
  4. V4 最後の収縮が10%以内(タイトであるほど良い)
  5. V5 出来高がドライアップしている(直近10日平均が50日平均の0.8倍以下)
  6. V6 ベース全体の期間が15〜200日
  7. V7 収縮のたびに安値が切り上がっている

VCPが完成しただけではまだ買わない。ピボット(直近の抵抗ライン)を出来高を伴って上抜けた瞬間が本来のエントリーポイント。

エントリー

  • ピボットを平時より多い出来高で上抜けたら買い(逆指値/成行のブレイクアウト買い)。
  • ピボットから大きく離れて(目安+5%超)追いかけない。過熱(EXTENDED)状態からの新規は避ける。
  • 地合い(市場全体のトレンド)が弱い時は新規エントリーの点数・サイズを絞る。

損切りとポジションサイズ

  • 1銘柄あたりの損切り許容は口座資金の1.25〜2%程度に収める。
  • 損切りラインは買値から-7〜8%を機械的な上限とする(それ以上待たない)。
  • ポジションサイズ = 許容損失額 ÷ (エントリー価格 - 損切り価格)で逆算する。損切り幅が広い銘柄ほど枚数を減らす。

利益確定と管理

  • 含み益が乗ったら損切りラインを建値まで引き上げ、無リスク化する。
  • 急騰(クライマックス的な値動き・出来高急増)は利益確定のサイン。
  • 勝ちトレードは伸ばし、負けトレードは素早く切る非対称性が最重要(勝率50%未満でも損益比で勝てる)。

このダッシュボードの〔本命〕〔候補〕〔監視〕はSEPAのステップに対応: 監視=8条件合格(ステージ2入り)、候補=VCP完成(テクニカルの引き金あり)、本命=ファンダメンタルズ裏付けまで確認済み。
