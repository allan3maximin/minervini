SEPAの基本サイクル

Mark MinervinìのSEPA(Specific Entry Point Analysis / 特定エントリーポイント分析)は、機関投資家の資金が入り始めた「成長株(スーパーパフォーマンス株)」を、ベースを抜けた瞬間に低リスクで拾いに行く順張り手法。株価は方向感の無い停滞から上昇、天井圏、下降という4つのステージを必ず巡っており、SEPAが狙うのはステージ2(上昇局面)の初期だけ。それ以外の局面では基本的に手を出さない。

SEPAは「テクニカルだけ」の手法ではなく、次の5つの柱を重ね合わせて判断する。

  1. トレンド(Trend) ステージ2にあること。すべての出発点で、これが無ければ他の条件が良くても買わない。
  2. ファンダメンタルズ(Fundamentals) 増収増益・利益率の改善など、株価上昇を正当化する業績の裏付け。
  3. 触媒(Catalyst) 新製品・新サービス・新経営陣・規制変更など、大口が買う「理由」となる出来事。
  4. エントリーポイント(Entry Point) VCP完成後のピボット。リスクが最小になる一点で仕掛ける。
  5. イグジット(Exit) 損切りと利確をあらかじめ決めておく。入る前に「どこで降りるか」を持つ。

この5つと市場全体の地合いが揃ったときに最も大きく張り、1つでも欠ければサイズを落とすか見送る。順序は「ステージ2で絞り込み → ファンダ・触媒で厚みを確認 → VCPでタイミングを計り → ピボットで入る → 決めたルールで降りる」。

ステージ分析(4つの局面)

株価は下の4局面をぐるぐる巡る。今どの局面にいるかを移動平均線の「並び」と「傾き」、そして出来高で見分ける。買っていいのはステージ2だけ。この判定を外すと、他がどれだけ良くても勝てない。

  • ステージ1(底固め・無関心期) 長い下落や急落のあと、値動きが横ばいのレンジに落ち着く。200日線がフラット化し、株価はその上下を行き来する。出来高は細り、世間の関心も薄い。ここでスマートマネーが静かに仕込む。まだ方向感が無いので買わず、監視リストに入れて待つ。数ヶ月〜年単位で続くこともある。
  • ステージ2(上昇・前進期) トレンドテンプレート合格の局面。50日 > 150日 > 200日の並びで各線が上向きになり、株価は高値・安値を切り上げる。押し目は出来高を減らして浅く作り、ブレイクは出来高を伴って上放れる。大陽線が多く、下げは短く浅い。唯一の買い場で、SEPAの全エネルギーをここに集中する。
  • ステージ3(天井圏・分配期) 上昇の勢いが鈍り、値動きが上下に荒くなる(ボラティリティ増大)。大口が一般投資家に静かに売り渡す「分配」の局面で、200日線の傾きが緩みフラットへ向かう。急騰後の乱高下・出来高を伴う大陰線が増える。新規は避け、保有は利確・一部利食いでリスクを落とす。
  • ステージ4(下降・下落期) 200日線が明確に下向きになり、50日 < 150日 < 200日のデッド順へ。戻りは戻り売りに押され、安値を切り下げる。出来高を伴う下げが目立つ。絶対に買わない(空売りを検討する局面)。「安くなったから」と拾うのが最も危険。

見分けの3軸: ①MAの並び(2はゴールデン順・4はデッド順) ②MAの傾き(200日線が上向きか下向きか) ③出来高(上昇日に増え、押し目に減るのが健全)。この3つが揃ってはじめてステージ2と判断する。ステージ1→2の転換初動を捉えられると、上昇のいちばん美味しい部分を取れる。

ファンダメンタルズ(業績と触媒)

大化け株の背後にはほぼ例外なく急激な業績改善がある。テクニカルは「いつ・いくらで買うか」を、ファンダは「なぜ大きく伸びるのか」を教えてくれる。両輪で見ることでブレイクアウトの成功率が上がる。

業績で見るポイント

  • EPS(1株利益)成長 直近四半期のEPSが前年同期比で大きく伸びている(目安+25%以上)。単発でなく複数四半期の継続が理想。
  • 成長の加速 成長率そのものが四半期ごとに上向いている(例: +20%→+35%→+60%)。減速局面より加速局面が強い。
  • 売上の伸び 利益だけでなく売上も伴って伸びている(コスト削減頼みの増益は息切れしやすい)。
  • 利益率の改善 営業利益率・純利益率が拡大している=ビジネスの質が上がっている。
  • ガイダンス・上方修正 会社予想やアナリスト予想が上振れ・上方修正されている。

触媒(カタリスト) — 大口が買う「きっかけ」。新製品・新サービスのヒット、新薬や新技術の承認、経営陣の刷新、業界全体の需要爆発、規制や制度の変更、大型受注など。強い決算サプライズそのものも触媒になる。

「良い会社」を探すのではなく「今まさに業績が変わりつつある会社」を探すのがコツ。ファンダが良くてもステージ2に入っていなければ待つ。逆にファンダの裏付けが弱いブレイクは、サイズを落とすか見送る。

トレンドテンプレート(8条件)

ステージ2にあることを機械的に確認するための8つのMUST条件。感覚を排し、1つでも欠ければステージ2とは認めない。

  1. 終値が150日線・200日線より上 — 中長期の買い方が利益を持っている状態。
  2. 150日線が200日線より上 — 中期の勢いが長期を上回っている。
  3. 200日線が最低1ヶ月(理想は4〜5ヶ月以上)上向き — 長期トレンドが確かに上を向いている。
  4. 50日線 > 150日線 > 200日線 の並び — 短中長期がきれいなゴールデン順。
  5. 終値が50日線より上 — 短期でも買い方優位。
  6. 52週安値から+25%以上離れている — 底値圏の停滞銘柄を除外(強いものは30〜100%以上離れる)。
  7. 52週高値から-25%以内(高値圏に近い) — 高値を更新できる強さがある銘柄に絞る。
  8. RSレーティングが70以上(理想は80〜90以上) — 相対的強さ。市場・同業と比べて明確に強い。

8条件は「入場資格」に過ぎず、合格しただけでは買わない。ここを通った銘柄の中から、ファンダと次のVCPで実際のエントリーを絞り込む。RSは高いほど良く、主導銘柄はRS90超が多い。

VCP(値幅収縮パターン, V1〜V7)

強い銘柄でも上昇前には必ず「収縮」する。上げが続くと利食い・投げが出て一度押すが、強い銘柄ほど押しが浅く・短くなっていく。この売り圧力の減衰=供給の枯れを、値幅と出来高の両面から確認するのがVCP(Volatility Contraction Pattern)。チャート上は左が深く右が浅い、階段状に締まっていく「足あと」として現れる。

  1. V1 収縮の回数 押し(収縮)が2〜6回。回数はTで数える(2T・3T…)。
  2. V2 収縮の深さが逓減 押しの深さが段階的に浅くなる(例: 25%→15%→8%)。これが最重要。
  3. V3 最初の収縮が35%以内 初回の押しが深すぎない(ダメージが大きすぎない)。
  4. V4 最後の収縮が10%以内 直前の押しがタイト(理想は数%)。タイトなほど良い。
  5. V5 出来高のドライアップ 収縮の終盤で出来高が枯れる(直近10日平均が50日平均の0.8倍以下)。売り手が居なくなった証拠。
  6. V6 ベース期間 ベース全体が15〜200日。短すぎず長すぎず。
  7. V7 安値の切り上がり 収縮のたびに安値が切り上がる(下値を支える買いが強い)。

V字急反発のように一気に高値へ戻る「ワイドでルーズ」なベースは、供給がまだ残っていて失敗しやすい。逆に、最後の収縮がタイト(数%)で出来高がカラカラに乾いているほど、わずかな買いで飛びやすい良形になる。ベースの中でエントリーを前倒しするチート(cheat)/ロー・チートという早仕掛けもあるが、まずは正統なピボット上抜けを基本にする。

VCPが完成しただけではまだ買わない。ピボット(直近の抵抗ライン=最後の小さな収縮の高値)を出来高を伴って上抜けた瞬間が本来のエントリーポイント。

エントリーの実例

ピボットは「最後の小さな収縮の高値=ベースの直近の抵抗ライン」。そこを平時より明確に多い出来高(目安: 50日平均の1.5倍以上)で上抜けたバーの引けで買うのが基本形。逆指値でブレイク価格に置いておき、抜けたら乗る形でも良い。狙いは「抵抗を抜けて、そこが今度は支持に変わる」瞬間。

良いブレイクアウト(仕掛けたい形)

  • 最終収縮がタイト(値幅10%以内、理想は数%)で、直前に出来高がドライアップしている。
  • ブレイク当日に出来高が急増(平均比+50%〜、理想は2倍前後)、ローソクの実体が大きく引けが高い。
  • ピボットからまだ+2〜3%以内で、追いかけずに済む位置で入れる。
  • 市場全体(指数)がステージ2で、地合いが追い風。同業・同テーマにも強い銘柄が並ぶ。

悪いブレイクアウト(だまし・見送る形)

  • 出来高が伴わない静かな上抜け(参加者が薄い=戻されやすい)。
  • ベースがワイドでルーズ、V字急反発で高値に戻ってきただけ。
  • ピボットから+5%以上離れて過熱(EXTENDED)、高値掴みになる位置。
  • 指数が調整・下落局面で、個別だけ突出している(続きにくい)。

ブレイク後にすぐピボットを割り込んで戻ってきたら「だまし」を疑う。損切りライン(リスク管理の項)に触れたら機械的に撤退し、同じ銘柄でも形が整え直すまで追わない。1回目が失敗しても、2回目・3回目のベースで決まることは多い。

地合い / 市場全体の判定

個別が良くても、市場全体が下落トレンドだとブレイクアウトの多くは失敗する。統計的にも個別株の値動きの多くは指数に連動するため、「指数がステージ2の時にフルに攻め、それ以外は守る」のが大原則。エンジンがかかった市場(market in gear)でだけアクセルを踏む。

  • フォロースルーデイ(FTD) 下げが一度底を試して反発した後、反発4〜7日目あたりで指数が出来高増を伴って+1.5%以上上昇する日。上昇トレンド転換の初動サインで、ここから新規の点数・サイズを段階的に上げていく。
  • ディストリビューションデイ(売り抜け日) 指数が前日より出来高を増やして下落する日。大口の売りを示す。短期間(3〜4週)に4〜5回積み上がったら、上昇トレンドの黄〜赤信号。
  • 攻めと守りの切替 地合い良好=新規を増やしフルインベストへ。地合い悪化=新規を絞る/サイズ縮小/現金比率を上げる/利の乗らない玉を外す。自分のブレイクアウトが失敗続きなのも、地合い悪化を示す生きたシグナル。

このダッシュボードの「市況概要」(指数カードの前日比グラデ)で全体の温度感をまず確認してから個別を見ると、逆風下での無駄なエントリーを減らせる。地合いの判定は個別の分析より先に行うのがコツ。

リスク管理・資金管理

SEPAの生命線は「損は小さく、利は伸ばす」の非対称性。勝率(バッティングアベレージ)が50%を割っても、平均利益が平均損失の2倍以上あればトータルで勝てる。だからこそ、当てることより「負けを小さく揃える」ことを最優先する。

  • 損切りは-7〜8%が機械的な上限 買値からこの幅に触れたら理由を問わず撤退。VCPが締まった良い位置で入れれば、実際の損切りはもっと浅く(-3〜5%)できる。上限は「これ以上は絶対に待たない」ライン。
  • 1トレードのリスクは口座の1.25〜2% 1回の負けで資金を大きく削らないための上限。連敗しても致命傷にならない水準に抑える。
  • ポジションサイズ = 許容損失額 ÷ (エントリー価格 − 損切り価格) で逆算する。損切り幅が広い銘柄ほど枚数を減らし、どの銘柄でも1回の負け額を揃えるのがポイント。「いくら儲かるか」より先に「いくらまで負けられるか」から株数を決める。
  • 集中しすぎない 同時保有は地合いに応じて数銘柄〜十数銘柄程度に分散。1銘柄への過度な集中は、1つの決算やニュースで口座が吹き飛ぶリスクになる。
  • 段階的な資金投入(プログレッシブ・エクスポージャー) 最初は試し玉で入り、含み益が出て正しさが確認できたら買い増す。うまくいっている時だけエクスポージャーを増やす。
  • 買い増し(ピラミッディング)は初動だけ ブレイク直後の含み益が出ている間に少量ずつ、平均取得単価を大きく引き上げない範囲で。伸びきってからの買い増しはやらない。
  • 連敗時は縮小 ドローダウンが続いたらサイズを落とすか一旦手を止める。地合いが戻り、自分のトレードが噛み合い出すまで無理に張らない。

利益確定とポジション管理

売りには「強さで売る(上げている最中に利確)」と「弱さで売る(崩れたら撤退)」の2種類がある。両方を状況で使い分ける。

  • まず無リスク化 含み益が乗ったら損切りラインを建値まで引き上げる(ブレイクイーブンストップ)。最悪でも負けないポジションにしてから利を伸ばす。
  • 弱さで売る(トレーリング) 利が乗った後は、直近スイングロー割れや50日線割れなど、トレンドが崩れたサインで手仕舞う。トレンドが続く限り持ち、崩れたら降りる。
  • 強さで売る(クライマックス) 急騰・出来高急増・連日の大陽線・窓を空けた飛びつき買いなどは「買われすぎ」のサイン。過熱した強さの中で一部を利確する。
  • 決算・イベント跨ぎ 決算跨ぎは一晩で大きく飛ぶ値幅リスクがある。ポジションサイズを事前に調整するか、跨がない判断も選択肢にする。
  • 非対称性を守る 勝ちトレードは伸ばし、負けトレードは素早く切る。これが崩れると、いくら良い銘柄を選んでもトータルでは勝てない。

このダッシュボードとの対応

本ダッシュボードの3ティアは、SEPAの絞り込みステップにそのまま対応している。上から順に条件が厳しくなる。

  • 〔監視〕 トレンドテンプレート8条件に合格(=ステージ2入り)。まだタイミングは来ていないが、ステージ2にある候補群。「あと一歩」「ベース形成中」などのセットアップ進行度で枠分けしている。
  • 〔候補〕 監視の中でVCPが完成し、テクニカルの引き金が整った段階。ブレイクアウト・ブレイクアウト直前など、実際に手を出しうる状態。
  • 〔本命〕 候補のうち、ファンダメンタルズの裏付けまで確認できたもの。SEPAの5本柱がもっとも揃った、優先的に狙うグループ。

毎日ざっと見るなら「市況概要で地合い → 監視の"あと一歩" → 候補/本命」の順が効率的。地合いが悪い日は無理に新規を探さない、というルールと合わせて使う。
