# 現行V1〜V7 vs 素直版 VCP 比較 (2026-07-25 15:48)

**差し替えたのは config["vcp"] の数値だけ。** vcp.py のコードには一切手を入れていない。
トレンドテンプレート(MUST)・RS>=rs_min・ブレイク判定(終値>pivot、60営業日以内)・
エントリー(ブレイク翌日始値)・損切り・EXTENDED除外・成績集計は全アーム共通。

**前提**: Minerviniの数値は米国市場のもの。日本市場で全部そのままに合わせると
エントリーが出なくなるため、V2/V4は重みが小さいと判断して意図的に緩めてある。
このレポートで本当に見たいのは **ATR除外 と V5** の2つ(由来が不明なもの)。
V2/V4の厳格版は参考情報として並べているだけで、戻すべきという主張ではない。

**既知の限界**: 現ユニバースで過去を見るため生存者バイアスあり。サンプルは
同一銘柄の再検出を含むため独立ではなく、期待Rは少数の大当たりで決まる。
そのため上位5%を落とした期待R(exp_r_trim95)と中央値Rを併記している。

## ATR除外ゲートの追加診断

`atr_exclude_threshold: 0.09` は `evaluate_vcp` の冒頭、`find_base_origin` より前に
`atr20/close > 0.09` の日を `TOO_VOLATILE` で打ち切る。この門が実際に何を切っているかを、
同じ 400営業日 × 992銘柄 のウィンドウで直接数えた。

| 項目 | 件数 |
| --- | --- |
| トレンドテンプレートMUST + RS>=70 を通過した日 | 57,584 |
| うち ATR20/close > 9% で打ち切られた日 | 1,104 |
| ↑ をゲート無しで再評価したときのステータス内訳 | TOO_RECENT 354 / IMMATURE 497 / REJECTED 229 / WATCH_B 24 / **WATCH_A 0** |

**この門が落としている WATCH_A は 400営業日で 0件。** セットアップ生成に関しては完全に
不活性で、成績の差もゼロ(検出集合が1件単位で一致)。理由は明快で、ATR20が9%を超えるほど
動く銘柄は、そもそもV4(最終収縮 <=12%)やV2(単調収縮)を通らない。つまりATR除外は
V2/V4が既にやっている仕事を、より粗い代理変数で前倒しにやっているだけ。

なお公開実装を調べた範囲で、ATRの**上限**で銘柄を除外しているVCP実装は見つからなかった
(ATRを使う実装は「動かなすぎる銘柄を弾く下限」として使う)。由来不明かつ効果ゼロなので、
残す積極的な理由は無い。ただし外しても何も変わらないので、外す緊急性も無い。
唯一の実害は、スクリーナーの診断出力で `TOO_VOLATILE` が真の除外理由に見えてしまうこと
(実際の理由は V2/V4 落ち)。

## 所見

### 1. ATR除外 — 不活性。効果ゼロ
上記のとおり。撤廃しても検出175件・期待R0.70が1件も動かない。

### 2. V5 — 現行の複合条件のほうが成績が良い
V5を「直近10日の出来高中央値 < vol_ma50」だけの素直版に戻すと、検出は
175→213件(+22%)に増えるが、期待Rは 0.70→0.61、上位5%除外後は 0.30→0.25 に劣化する。
つまり現行の 0.85倍しきい値と回帰スロープのOR分岐は、**由来は不明だが選別としては効いている**。
増えた54件の新規検出のほうが平均的に弱い、という素直な読み方ができる。

ただし注意: 差は 0.70 vs 0.61、実測サンプルは131 vs 160件しかなく、中央値Rは両者とも -0.20 で
同じ。統計的に有意と言える差ではない。「素直版に戻す積極的理由は無い」までは言えるが、
「現行が優れている」とは言えない。

### 3. V2 — 締めると数が減り、質は上がる(が期待Rはほぼ同じ)
厳格化すると検出175→119件(-32%)。期待Rは 0.70→0.76、上位5%除外後 0.30→0.39、
中央値Rは -0.20 → **+0.09** とプラス転する。+20営業日の中央値も -1.39% → +0.05%。
「日本市場では緩めないとエントリーが出ない」という判断と整合的な結果で、
緩和は**数を買って質を売る**トレードだったことが数字で確認できた。意図どおり。

### 4. V4 — 12%→10%は効果が小さい
検出175→167件(-5%)、期待R 0.70→0.66。落ちた8件が特別悪いわけではない。
V4のしきい値はこの範囲ではほぼ無関係。緩めた判断に問題は見当たらない。

### 5. 全部素直版 — 現行より悪い
検出135件、期待R 0.57、上位5%除外後 0.20。V2厳格化の質向上を、V5素直化の質劣化が
打ち消して、さらに下回る。**全部Minervini/公開実装に寄せるのが正解、ではない**ことは
このデータの範囲では確認できた。

### 6. 集計上の注意
- `strict_v2` に「当該アームのみ 3件」があるのは、ピボット±1%重複排除の副作用。
  先行するセットアップが弾かれた結果、後続が重複扱いされずに残ることがある。
- `base_max_days` を 325 に上げるだけでは効かない。`find_base_origin` が
  `scan_days_extended`(既定200)でベース長を頭打ちにするため、探索窓も伸ばす必要がある。
  `plain_all` では両方を325にしている。
- サンプルは同一銘柄の再検出を含み独立ではない。期待Rは少数の大当たりで決まるため、
  アーム間の 0.05〜0.1 程度の差を根拠に設定を動かすべきではない。
