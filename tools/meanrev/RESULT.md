# 型1(短期売られすぎリバウンド)検証まとめ

2026-08-19 時点。log.md の 179〜184 を通しで読める形に圧縮したもの。
細かい途中経過と反省は log.md 側に残してある。

---

## 1. 何を作ろうとしていたか

既存のミネルヴィニ式スクリーナー(2026-10 までフォワード検証中・凍結)とは
**別のツール**として `tools/meanrev/` を新設した。既存のコード・パラメータには
一切触れていない(`data/audit_cache/` を読むだけ)。

狙いは置き換えではなく**併用**。ミネルヴィニのほうは上位15%の大きな勝ちが
期待値の大半を背負う形で、損益が少数の取引と強気相場に寄りかかっている。
損益の出方が違う2本目の柱が欲しい、というのが動機だった。

| | ミネルヴィニ式(既存) | 型1リバウンド(ここ) |
|---|---|---|
| 買う対象 | 強い銘柄 | 一時的に売られた銘柄 |
| 想定 | トレンド継続 | 平均回帰 |
| 損益構造 | 低勝率・大きな勝ち依存 | 高勝率・小さな利益 |
| 保有 | 10〜15日 | 数日 |

前提として最初から固定したもの:

- **コスト 片道0.15%(往復0.3%)を全部の数字に入れる。** 後から入れると結論がひっくり返る
- エントリーは引成(シグナルの出た日の終値で買う)
- ストップ安張り付きは除外(拾えないものを拾ったことにしない)
- 分割調整の壊れた行は除外

## 2. 効いた形にたどり着くまで(179〜181)

### 買う条件は3系統が同じ向きに効いた

RSI(2)<5 / 4日連続陰線 / ボリンジャー下限割れ。どれも同じ方向に効いた。
一方で「直近高値からの下落率」は効かなかった。以後は RSI(2)<5 を代表に使う。

### 降り方を間違えると勝率が13ポイント消える(180)

最初に固定5日で測って勝率50.2%しか出ず、想定の60〜70%と食い違った。
原因はシグナルではなく**測り方**で、反発し終わった後も日数が来るまで
持ち続けて戻されていた。降り方を「反発したら降りる」に変えるだけで:

    固定5日                      勝率 50.2%  期待R +0.023
    RSI(2)>70で降りる(上限10日)  勝率 63.5%  期待R +0.059
    5日線を超えたら降りる         勝率 63.2%  期待R +0.052
    1日でも上げたら降りる         勝率 62.5%  期待R +0.008 ← 勝率だけ高く中身が無い

平均回帰では固定日数のほうが特殊な形だった。以後は「RSI(2)>70で降りる」を使う。

**コストが期待値の7割を食っている。** 往復0.3%を外すと +0.023 → +0.083。
片道0.15%という前提を動かすと結論が変わる領域にいる。

### 自分で未来情報を仕込んで10倍の数字を出しかけた(180)

「連続して条件を満たした期間の最後の日で買う」で期待R +0.319 が出た。
全部嘘で、実装が「翌日は条件を満たさない日」= 翌日上げた日 を選んでいた
(翌日プラス率94.5%)。`exits.py` にコメント付きで残してある。

**教訓: 期待Rが桁で跳ねたら、まず自分の実装を疑う。** シグナルの定義だけでなく
「どの日を代表として取るか」の間引きまで遡って確認する。

### 損切りは構造的に合わない(181)

損切り1Rを入れると期待値がほぼ消える(楽観 +0.002 / 悲観 -0.065)。
理由も測った:

    損切りにかかった割合                        35.5%
    かかった回を損切りせず最後まで持った場合の平均 -5.08%(勝率17.7%)
    損切りで確定する損(平均)                    -6.14%

損切りは**悪い回を正しく見分けている**。それでも損になるのは、確定する損のほうが
持ち続けた場合より大きいから。一番下で投げている。「一番売られたところで買う」戦略に
「もっと売られたら降りる」を足すのは自分の前提を否定している。

### そして最初の結論: 2本目の柱にならない(181)

下げ相場では稼げなかった。理由は3つに分かれる。

(a) リバウンドの上乗せ自体は下げ相場でも消えていない(リーマンでの上乗せは全局面で最大)
(b) それでも手取りはマイナスかゼロ。買い持ちしかしないので相場の下げに負ける
(c) **そもそも下げ相場では買う対象がほぼ無い。** 母集団が1日10〜40銘柄
   (上げ相場は220〜318)。3年間で283回しか取引が発生しない

(c) が決定的で、これは母集団の条件が**ミネルヴィニと同じ(200日線の上・上向き)**
だから起きていた。探す場所が同じなら分散にならない。

## 3. 母集団を作り直した(182)

「200日線の上」をやめて「市場より強い上位3割(RS70以上)」に変えた。
機会は3倍になった。ただし**負ける場所は直らなかった**。

分かったのは、型1が負けるのは「下げ相場」全般ではなく
**一方通行で崩れ始めた最初の数週間だけ**ということ。2020年は2月だけで
年間の負けを全部作っている。

そして**指数の位置と傾きだけでは、ただの押し目と本物の崩れを切り分けられなかった。**

---

## 4. 既にある地合いシグナルを使ってみた(183)

`src/report/market_signal.py` の攻め/中立/守りを歴史ぶん再現して当てた。
効いた。**ただし向きが逆だった。**

    攻め   手取り +0.10%
    中立   手取り +0.81%
    守り   手取り +0.73%

攻め+中立に絞ると悪化(+0.53% → +0.40%)、攻めを外すと改善(+0.76%)。
理由は「強い相場の日に RSI(2)<5 まで売られる銘柄は、自分固有の問題を
抱えているので跳ねない」。

ただし守りの良い平均は**上げ相場の中の短い押し目**が作っていて、本物の
下げ相場は横ばいかマイナス(リーマン +0.17%、2020 -1.96%)。
「危ない日」を検出する条件(幅の急低下・ボラ1年高値圏など)を何通り試しても、
**一番儲かる日に反応した**。2020年2月はどれでも外せなかった。

**→ この結論は 184 で粗すぎたことが分かり、上書きされている。**

## 5. 採用案: 巻き添えで落ちたやつを狙う(184)

### 途中で一度間違えた(重要)

「市場よりどれだけ余計に落ちたか」だけで切ると、単独急落側 +1.05% /
巻き添え側 +0.73% のU字になり、「単独急落を狙え」という逆の結論が出る。

原因は**軸が2本混ざっていたこと**。市場より余計に落ちた銘柄は、そもそも
落ち幅自体が大きい。落ち幅が大きいほど儲かるので、単独急落側が良く見えて当然だった。

落ち幅を -10〜-4% に固定して市場との差だけで切り直すと、きれいに一直線になる:

    単独で急落した側  +0.02%
                     +0.13%
                     +0.53%
    巻き添え側        +1.20%(勝率75.6%)

**教訓: 都合の悪い数字が出たときも、軸が混ざっていないかを先に疑う。**

### 採用した形

「巻き添え」を測るのに、市場との差より素直な指標があった。
**その日、母集団のうち何%が同時に RSI(2)<5 まで売られているか**。
1銘柄だけなら自分の問題、8%が一斉なら巻き添え。

**一斉8%以上 ∧ 落ち幅10%以上**

| | |
|---|---|
| 件数 | 3,437(年134回) |
| 勝率 | 69.0% |
| 手取り | **+2.58%/回**(無条件買い +1.13%、上乗せ +1.44%) |
| 前半(〜2014) | +3.17% |
| 後半(2015〜) | +2.22% |
| 期待R | +0.278 ±0.038 |
| 勝ち平均 / 負け平均 | +7.29% / -7.95% |
| 下位1% | -24.93% |

**採用条件4つすべて通過。** しきい値はどちらも崖ではなく坂:

    一斉度  0%→+1.72%  …  20%→+3.51%
    落ち幅  0%→+0.95%  …  -20%→+5.82%

前半・後半とも全ステップでプラス。つまり「8%」「10%」に特別な意味はない。
厳しくすれば取り分が増えて回数が減るだけで、年134回はその中間を取っただけ。

### 183 の結論を訂正

「攻めの日は買うな」は粗すぎた。正しくは
**「攻めの日に1銘柄だけ売られたときがダメ」**。

    攻め + 一斉4%未満  -0.42%   /  攻め + 一斉8%以上  +0.48%
    中立 + 一斉4%未満  +0.12%   /  中立 + 一斉8%以上  +1.05%
    守り + 一斉4%未満  -0.03%   /  守り + 一斉8%以上  +1.12%

どの地合いの中でも一斉度が効いている。つまりこれは地合いの言い換えではなく、
独立した情報。

### 181 の結論を部分的に撤回

局面別で、十分な件数がある10局面すべてがプラスかゼロ近辺:

    2007-09 リーマン   n=451  勝率 70.1%  +2.39% ±0.141
    2020    コロナ     n=366  勝率 60.9%  -0.08% ±0.136
    2021-22 グロース崩壊              +0.51%
    2023-24 日経高値・24年8月暴落     +4.74%

負けた年は25年中3年だけ(2019 -0.4% / 2020 -0.1% / 2022 -0.4%)。

**下げ相場で稼ぐわけではないが、溶けなくなった。**
「2本目の柱にならない」は、この形では言い過ぎになった。

## 6. 残っている穴

**2020年2月は -13.50%(60件)。** フィルタを通した後でもこれ。
市場全体が巻き添えになる月は、巻き添え狙いの戦略には避けようがない。
構造的な話なので小細工では消えない。

年で見ると3〜6月のリバウンドが返して -0.08% に収まる。ただし
**「1か月で二桁マイナスを食らう」前提で建玉数を決める必要がある。**
