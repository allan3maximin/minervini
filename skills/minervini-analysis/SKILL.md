# ミネルヴィニ式(SEPA)銘柄分析スキル

貼り付けられたスクリーナー出力データを、マーク・ミネルヴィニのSEPA手法で読み解く。

## 入力データの構造

ダッシュボードの個別株画面「分析用データをコピー」が生成するMarkdownブロック。セクション構成:

1. **ヘッダ**: コード/銘柄名、データ生成日時、ティア、エントリーステータス、セクター(強度/方向)
2. **価格・テクニカル**: 終値、RS(1-99パーセンタイル、母集団はユニバース約1000銘柄)、ピボット、推奨逆指値、推奨損切り、リスク%、ピボット距離、52週高値距離、MA乖離(50/150/200)、EPS加速slope
3. **スコア**: テクニカル/フル/VCP/総合(いずれも0-100)。順位付けは全ティアともテクニカル+VCPの純セットアップ品質(フルスコアは表示専用の参考値)
4. **トレンドテンプレート8条件**: ✓/✗のチェックリスト
5. **VCP条件 (V1〜V7)**: ✓/✗ + フットプリント(例: `3T 25/12/6` = 収縮3回、深さ25%→12%→6%)。「VCP評価なし」の場合はセットアップ未形成
6. **直近の値動き**: 直近20営業日のOHLCV表 + 5/20/60日騰落率 + 出来高10日/50日平均比(≤0.8でドライアップ水準)
7. **ファンダメンタルズ**: 四半期ごとのEPS/売上高とYoY(Q4はFY通期扱い)+ ファンダ強度判定 + **サイズ係数**(pass=1.0フルサイズ / unknown=0.5ハーフサイズ / fail=0エントリー取り止め。RSが業績を織り込むためファンダはランキング非算入で、エントリー可否とロット確信度にのみ使う設計)
8. **市況コンテキスト**: 主要指数の前日比、ユニバースの8条件合格率、ブレイクアウト成功率

### ティアの意味
- **本命 (confirmed)**: 8条件合格 + VCPセットアップ + ファンダ強度合格(直近EPS YoY≥+25%かつ売上YoY≥+20%)
- **候補プール (pool)**: テクニカル/VCPは揃っているがファンダ未確認、または強度基準未達(「ファンダ強度判定: 不合格」行あり)
- **候補 (watchlist)**: 8条件合格のみ、セットアップ形成待ち
- **追いかけ禁止 (cooled)**: ブレイク済みで手遅れ(EXTENDED=伸びすぎ / STALE=鮮度切れ)。
  ピボット・損切り情報は保持されているが新規エントリーは不可。次のベース形成を待つ。
  watchlist(形成待ち)とは意味が違うため別ティアに隔離されている。

### エントリーステータスの意味
- `BREAKOUT`: 当日ピボット突破+出来高伴う → 即行動対象
- `BREAKOUT_WEAK`: 突破したが出来高不足(50日平均×1.4未満) → 疑わしいブレイク、フォロースルー確認
- `WATCH_A`: ピボット確定済み、突破待ち → 逆指値セットの検討対象
- `WATCH_B`: ベース形成中
- `EXTENDED`: ピボットから伸びすぎ → 追いかけ買い禁止(cooled ティアに表示)
- `STALE`: ブレイク鮮度切れ(初回ブレイクから7暦日超、EXTENDED も同様に変換) → 追いかけ買い禁止、新ベース形成待ち(cooled ティアに表示)
- `REJECTED`/`IMMATURE`/`TOO_RECENT`/`NO_BASE`: ベース不成立系

## 分析手順

以下の順で評価し、各項目に根拠(貼られた数値)を必ず添える。

### 1. トレンド判定(ステージ分析)
- 8条件の✓/✗を確認。1つでも✗があればステージ2上昇トレンドとして不完全 → 原則見送り。
- MA乖離から位置関係を読む: MA50乖離が大きすぎる(目安+20%超)なら過熱、マイナスなら50日線割れ。
- 52週高値距離: -25%以内が条件だが、理想は-15%以内。高値更新間近(-5%以内)なら抵抗が薄い。

### 2. ベース/VCP品質
- V1〜V7の✗の内容を具体的に指摘(例: V4✗=最後の収縮が10%超 → まだ煮詰まっていない)。
- フットプリントの収縮列が段階的に減少しているか、最後の収縮が一桁%か。
- 出来高比率: ≤0.8はドライアップ(良兆候)。ブレイク時は逆に50日平均×1.4以上が欲しい。
- 直近20日のOHLCVから: レンジの締まり具合、安値切り上げ、出来高の枯れ→急増パターンを読む。

### 3. ファンダメンタルズ(Code 33 / 加速)
- EPS YoY: 直近2〜3四半期で+25%以上が理想。**加速**(伸び率自体が拡大)していれば加点。
- 売上YoY: +20%以上が理想。EPSだけ伸びて売上が伸びていない場合はマージン頼みと指摘。
- EPS加速slopeがマイナスなら減速傾向として明示。
- **データの癖に注意**: Q4はFY通期扱い。最古のQ4行は通期累計値が混じることがあり、YoYが異常値(±50%超の不自然な変動)なら「データの癖の可能性」と断り、鵜呑みにしない。

### 4. エントリー計画
- ステータス別の行動: WATCH_A→逆指値(推奨逆指値の値)セット検討 / BREAKOUT→当日出来高確認 / BREAKOUT_WEAK→フォロースルー待ち / EXTENDED・STALE→次のベースまで待つ。
- リスク%(逆指値→損切り)が5%以内か確認。超えるならポジション縮小かエントリー見送り。
- ポジションサイズの考え方を提示: 総資金の口座リスク(0.5〜1.25%)÷リスク% = ポジション比率。具体額は資金額を聞かれない限り比率で示す。
- **サイズ係数を必ず反映**: fail(係数0)ならセットアップが完成していても「見送り」判定にする。unknown(係数0.5)なら許容損失を半分にしたハーフサイズを提示。pass(1.0)はフルサイズ可。

### 5. 地合い・セクター
- 指数前日比が軒並みマイナス(特に-2%超)なら「地合い逆風、新規エントリーのサイズを落とすか見送り」と明示。
- 8条件合格率: 10%未満は弱い地合い、20%超は強い。
- セクター強度「弱」や方向「↓」なら、個別が良くても向かい風と指摘。

## 出力フォーマット

```
## 総合判定: {エントリー可 / エントリー準備(監視) / 保留 / 見送り}

(2〜3行の結論サマリー)

### 強み
### 弱み・懸念
### 具体的なアクション
(逆指値・損切り・サイズ・確認すべきこと)

### 免責
```

- 判定は必ず4択のどれかに落とす。曖昧に濁さない。
- 数値の引用は貼られたデータのみ。**データに無い数値を推測で補わない**。欠けていて判断に必要なら「〜のデータが無いので確認して」と明示的に求める。
- データはEOD(日足終値)ベース。ザラ場の値動きは反映されていない旨を必要に応じて言及。
- 最後に必ず短い免責を付ける: 投資助言ではなく、最終判断はユーザー自身が行うこと。

## 禁止事項

- 貼られたデータの生成日時が古い(数日以上前)場合、そのまま「今日の判断」に使わせない。最新データでの再確認を促す。
- 「絶対上がる」等の断定的な将来予測をしない。
- ユーザーの資金状況を勝手に仮定した具体的な発注指示をしない(比率・条件で示す)。
